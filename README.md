A standalone Git forge with Git smart HTTP, GitHub-compatible REST and GraphQL APIs, and MCP tools backed by shared repository state.

## Run it

The make.fun runtime supplies `MAKEFUN_ENV_URL` and may supply `MAKEFUN_SHOP_TOKEN`.

```sh
node main.ts
```
